# 💙 Something For You

A magical, interactive web experience built with pure HTML5 Canvas and vanilla JavaScript. Designed with smooth particle physics, a starry ambient heart field, dynamic text swarms, and a playful interactive mini-game.

## Features

* **Interactive Particle System:** Built entirely with HTML5 Canvas and 2D context rendering—no heavy external game engines.
* **Custom Cursor Butterfly:** A delicate winged particle swarm that gracefully follows your cursor.
* **Dynamic Text Swarms:** Headings and buttons assemble smoothly from floating individual light particles.
* **Playful Mini-Game:** A cheeky interactive button that dodges your mouse or touch clicks before revealing a fun surprise!
* **Glassmorphism UI:** Modern frosted glass login and card UI styling powered by Tailwind-inspired CSS and Google Fonts (*Poppins* & *Dancing Script*).
* **Fully Responsive:** Optimized smoothly for both desktop pointers and mobile touch screens.

## Built With

* **HTML5** & **CSS3** (Glassmorphism, Flexbox, Keyframes)
* **Vanilla JavaScript** (Custom physics, trigonometric motion, offscreen canvas pixel sampling)
* **Google Fonts** (Poppins, Dancing Script)
